# WebTech Inspector

פרויקט בקורס תכנות מתקדם. התוכנה מזהה טכנולוגיות מתוך נתוני דוגמה ומדפיסה דוח סיכונים.
הכל רץ מקומית, בלי אינטרנט ובלי ספריות חיצוניות.

## מה צריך
Python 3.10 ומעלה.

## הורדה
```
git clone https://github.com/alon121/ono-final-project-advanced-programming.git
cd ono-final-project-advanced-programming
```

## הרצה
```
python main.py
```
